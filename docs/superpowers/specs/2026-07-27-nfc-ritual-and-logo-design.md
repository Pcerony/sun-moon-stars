# NFC 仪式动效与 Logo 应用设计

## 目标

强化“太阳与月亮”原型中最重要的 NFC 交互，使真实扫描具有明确、精美且富有仪式感的成功反馈，同时保持现有卡通手绘、贴纸与公园自然风格。

本设计包含两套不同的 NFC 成功仪式：

- 月亮项链扫描：表达太阳与月亮成为伙伴。
- 星星徽章扫描：表达太阳与月亮共同完成任务并收藏星星。

两套动效共享颜色、波纹、贴纸弹性、声音和震动语言，但不能复用同一套叙事动作。

## 动效原则

- 动画服务于读取状态和活动叙事，不作为持续装饰。
- 正式成功画面只能在 NFC 确实读取成功后播放。
- 隐藏测试模式的模拟扫描与真实 NFC 共用同一套成功流程。
- 动效不能改变页面固定布局尺寸，也不能与底部 Dock 或文字发生遮挡。
- 正常模式下完整仪式约为 3 至 3.5 秒。
- 开启 `prefers-reduced-motion` 时，改为不超过 0.6 秒的淡入、状态切换和静态成功画面。
- 动效播放期间锁定重复扫描，结束后再执行下一次页面转换。

## 通用扫描状态

所有 NFC 入口使用同一套状态模型：

1. `idle`：显示扫描按钮和当前任务内容。
2. `scanning`：启动 Web NFC，显示柔和循环水波和极短的等待文字。
3. `success`：停止等待水波，播放对应的完整仪式。
4. `error`：停止全部成功动效，显示现有错误提示并返回可扫描状态。
5. `complete`：仪式播放结束，提交现有状态转换并进入目标页面。

真实 NFC 与模拟扫描只共享成功后的视觉控制器；模拟控制本身仍只在长按标题开启的开发模式中出现。

## 月亮项链：伙伴配对仪式

### 叙事

这一套动效只出现太阳与月亮，不出现星星。重点是两个原本分开的参与者建立联系并成为伙伴。

### 时间顺序

1. NFC 读取点产生两圈柔和水波，表示设备已经成功读取。
2. 太阳元素从左侧进入，月亮角色从右侧进入。
3. 两者短暂绕行、靠近，珊瑚色连接光点出现。
4. 太阳与月亮收拢成一张共同的伙伴贴纸。
5. 贴纸轻弹，周围出现少量星光纸屑。
6. 播放一次短震与柔和清脆的提示音。
7. 动效结束后进入月亮名片页面。

### 正式素材

月亮角色必须使用项目所有者后续提供的正式插图。正式插图提供前，不把动效示意稿中的圆形“月亮”占位图用于正式网页。

太阳元素沿用当前视觉系统的暖黄色太阳标识；它只在这一套配对仪式中作为叙事角色出现。

## 星星徽章：共同收藏仪式

### 叙事

太阳和月亮一起接住任务星星，再共同把它送入队伍星空。该动作强调合作完成，而不是由某一方单独领取奖励。

### 时间顺序

1. NFC 读取点产生水波，任务星星从读取位置弹出。
2. 太阳和月亮从两侧同步向中心靠近，共同围住星星。
3. 不使用抽象手臂、连接棍或难以识别的辅助线条。
4. 屏幕上半区整体展开为深青色共同星空。
5. 星星沿短轨迹向上飞入星空。
6. 新星星在星空中轻弹并点亮，积分同步出现。
7. 播放两次短震与更明亮的上行提示音。
8. 动效结束后进入现有任务完成页面。

### 与配对仪式的区别

- 配对仪式是“两个伙伴彼此靠近并组成贴纸”。
- 收藏仪式是“两个伙伴共同接住星星并送入星空”。
- 配对使用柔和单音与单次震动；收藏使用上行音与两次震动。
- 星星收藏的上半屏星空是主要舞台，不使用小型星空卡片。

## 声音与震动

- 声音使用 Web Audio 动态生成，不增加外部音频文件。
- 声音必须从用户主动发起的扫描操作开始准备，遵守浏览器自动播放限制。
- 月亮配对：一次短震，单个柔和高音。
- 星星收藏：两次间隔短震，两个上行音。
- 不支持震动或音频的设备仍能通过画面完整理解结果。
- 减少动态效果模式保留极短确认音，但不播放连续或延迟音效。

## 错误与中断

- NFC 不可用、读取失败或用户拒绝权限时，不播放太阳、月亮、星星或积分成功画面。
- 错误提示沿用现有顶部提示组件，不新增说明卡片。
- 扫描失败后恢复原按钮，允许再次操作。
- 页面离开、返回首页或打开备用地图时，立即停止未完成的动效、声音和震动。
- 动效完成后才提交配对或积分状态，避免画面失败但状态已经前进。

## Logo 应用

正式 Logo 来源为 `img/logo.png`，原文件为 200 × 200、带透明通道的 PNG。

实施时把正式使用副本放入 `assets/branding/logo.png`，保留原始参考文件不变。

Logo 只出现在关键品牌位置：

- 底部 Dock：首页小房子图标替换为 Logo；当前首页状态继续使用黄色圆形底。
- 欢迎页：在主要插图或标题附近出现一次完整 Logo。
- 浏览器 favicon：使用 Logo。

Logo 不用于：

- 每个页面标题；
- 任务贴纸和状态数据；
- 月亮、太阳或星星角色的替代品；
- 每张任务插图或每个成功画面的重复水印。

## 代码边界

- `src/state.js` 继续只负责持久工作流状态，不保存逐帧动画状态。
- 新增独立的 NFC 仪式控制模块，负责等待、成功、错误、完成和清理。
- `src/nfc.js` 继续只负责 Web NFC 能力与读取。
- `src/app.js` 负责选择当前仪式、渲染动效层并在仪式结束后提交既有状态转换。
- CSS 动画集中在 NFC 仪式组件样式区，避免散落到普通页面组件。

## 测试与验收

- 状态测试覆盖：扫描成功前不提前配对或加分、成功后只提交一次、失败后状态不变。
- 浏览器流程覆盖真实扫描适配器的模拟结果和隐藏开发扫描。
- 检查 320 × 700、390 × 844、460 × 900 三种视口。
- 检查动效层、底部 Dock、提示文本和浏览器安全区没有遮挡。
- 检查中文与英文短文案均不溢出。
- 检查 `prefers-reduced-motion`。
- 检查普通参与者页面没有测试或原型控制。
- NFC 实机结果只能在 Android Chrome、HTTPS 和实体标签环境中确认；桌面模拟不能替代硬件验收。

## 实施顺序

1. 接入 Logo，并完成 Dock、欢迎页和 favicon 的视觉检查。
2. 建立通用 NFC 仪式状态与可清理的动效层。
3. 在正式月亮插图提供后实现伙伴配对仪式。
4. 实现共同收藏星星仪式。
5. 补充声音、震动和减少动态效果。
6. 完成状态测试、完整模拟流程和移动端视觉验收。
