# Moving Memories

Moving Memories（移动记忆）是大濠公园活动的手机 Web 原型。年长参与者“月亮”使用纸质地图负责整体方向，年轻参与者“太阳”使用手机完成 NFC 配对、任务提示、任务探测与徽章收集。

## 当前功能

- 产品名称统一为 Moving Memories，首屏使用正式太阳插图，不再使用 AI 双人插图。
- 欢迎页“开始”会直接启动月亮项链 NFC 配对，不再增加重复确认。
- 初次配对后首页先保持空白，通过再次扫描月亮项链解锁当前区域内的任务。
- 点击已发现的任务会进入近距离探测器；找到位置并结束探测后，再扫描月亮项链解锁任务详情。
- 星星徽章使用太阳与月亮共同接住并收藏星星的独立仪式动效。
- NFC 成功仪式使用更清晰的成功音、延长的末帧停留和覆盖下一页的柔和淡出。
- 首页显示模拟的当前区域、温度、步数和积分；区域解锁后才显示附近任务。
- 活动任务按地图区域批量配置：摸小狗、浇花、和工作人员抱抱、抱抱大树、听小桃桑的音乐会、在大树下休息五分钟、体验 VR、画一株植物、和小朋友玩翘翘板。
- “寻找彩蛋”是可重复分布在各区域的 NFC 彩蛋；找到后跳过任务详情，直接扫描彩蛋星星收集积分。
- 以太阳为中心的任务探测器会自动使用方向传感器、震动和声音反馈；接近目标后进入任务详情解锁流程。
- 通过 NFC 星星徽章完成任务后直接返回首页，并更新积分和队伍星空。
- 纸质地图负责主要导航；手机中的活动地图只作为备用查看。
- 默认中文，可切换英文。
- 正式 Logo 用于欢迎页、页头、底部首页入口和浏览器图标。

## 本地运行

```sh
python3 -m http.server 8080
```

打开 `http://localhost:8080`。长按页面左上角“Moving Memories”约 1.2 秒，可显示本地测试控制；普通参与者不会看到这些控制。

## NFC 实机测试

Web NFC 只在支持 NFC 的 Android Chrome 和 HTTPS 环境中可用。当前原型接受可读取的通用 NDEF 标签，标签内容不会上传。

扫描等待阶段只显示感应波纹；成功读取后才播放对应仪式并更新配对、任务或积分。声音、震动和方向传感器不可用时不会破坏主要流程。
